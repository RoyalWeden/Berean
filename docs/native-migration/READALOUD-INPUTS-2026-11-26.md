# Read Aloud model inputs, November 26

The standalone Swift probe matches the installed Kokoro 1.2.1 model-input path for an explicit Unicode-scalar tokenizer fixture. Transformers.js 3.8.1 supplies the original tokenizer side of the comparison. The probe also compares all 256 Float32 style values, bit for bit, using the installed Heart and Emma voice files and Kokoro’s actual style selection. The model call is replaced by an input recorder.

Mac input-only run passed 68 cases. Each voice covered 26 English samples phonemized with its original accent and eight supplied IPA cases. The supplied inputs cover empty input, spacing and combining marks, unknown scalars, and truncation around the 512-token limit. The Swift executable cross-compiled and ran on arm64 iPhone Simulator. The Simulator passed all 68 fixture token-ID and installed voice-style cases, exit 0. See `/private/tmp/berean-kokoro-inputs-ios-20261126.log`. This validates fixture tokenization and real style bits. The recorded model inputs did not reach ONNX inference or audio playback. Explicit ESLint and JavaScript syntax checks passed.

The existing full native phonemizer assertions remain in the default run. A fresh full run first encountered a SwiftPM module-cache permission error, then a nested manifest permission error with a temporary cache. The file-only retry reached the cached eSpeak package but could not resolve its uncached eSpeak NG and Sonic submodules. It did not rerun the earlier native IPA checks.

The tokenizer fixture does not contain production token IDs. The original app uses fp32 weights in `onnx/model.onnx`. The old q8 export garbled speech, so the earlier q8 description in the parity table is historical. The remaining engine checks are the original model tokenizer assets, fp32 CPU inference and 24 kHz PCM, timing/cancellation, and listening quality. Existing G2P licensing and resource provenance approval applies before app linkage. No model downloads, production model-cache access, app dependency changes or audio playback occurred.
