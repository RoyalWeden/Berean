## B. Mac — clickable pointer and UX polish (code audit)

The shared modifier `View.clickableCursor(_:)` was added in `ScriptureView.swift` next to `InteractivePlainButtonStyle`
(2026-11-14). Plain buttons use `.buttonStyle(.interactivePlain)`. Everything else (Menus, Pickers, Toggles, toolbar and
bordered buttons) uses `.clickableCursor()`. Apply it to a container only if that container has no TextField.

Call sites that lacked a hand cursor on 2026-11-14:
- GoSheet: result and shortcut rows; Cancel.
- CompareView: Cancel; manage-translations Menu.
- DailyNoteCalendar: chevrons, Current Month, Today's Note, Sunrise; the sunrise sheet buttons.
- HistoryView: Picker, Toggle, Show Older, Clear.
- NotesHome: toolbar Back / View Options / New Folder / New Note; search-options Menu.
- NotesViews: toolbar All Notes / Format / History / Share / Pin / Trash; Save Version Now; Done / Restore.
- ScriptureSearchView: scope Menu, option Pickers, Reset / Clear / Search All Texts buttons.
- SettingsView: Form controls; workspace Open + Menu.
- StudyTrailView: rows, New Trail, stop rows, record / pause / resume / finish, connection buttons, Done.
- TabCleanupView: toggles, Select All / Clear Selection, Cancel / Archive.
- Also: TagManagerView New Tag; VerseTagViews create / Cancel / Add; StudyViews Pickers; PassagePicker text Picker;
  StudyInspector panel Picker; Sidebar tab-type Picker / Cancel / Done / workspace Menu; MacRootView Layout Menu;
  ScriptureView ContentUnavailableView buttons.
- RichNoteEditor note links: `linkTextAttributes` cursor.
- Native alert and confirmationDialog buttons are system-drawn and cannot take a pointer.

Other polish findings:
- **Colours.**
  - White text on accent fills is unreadable with a light accent: StudyInspector 153-159, PassagePicker 348, IOSRootView 108.
  - The search match highlight is a fixed `Color.yellow.opacity(0.35)` (ScriptureSearchView ~521).
  - The sidebar active row uses white / black literals (Sidebar 504).
- **Touch targets under 44 pt (iOS).**
  - Dock buttons are 46×30 (IOSRootView 107).
  - The Notes search-options Menu is 28 pt (NotesHome 249).
  - The clear (×) buttons have no frame.
  - The calendar chevrons and the Sunrise button.
- **Animations.**
  - Only Sidebar and MacRootView animate.
  - Missing: cross-reference disclosure (StudyViews 628), Show Older, notes list pin / delete / trash, tag create / merge / delete,
    Study Panel / Compare / Strong's toggles, GoSheet result sections, Study Trail status, TabCleanup selection.
- **Silent `try?` on user actions.** Tag create / rename / merge; note delete then navigate away; Save Version Now; Restore
  Version; folder create / delete / deep-delete; empty trash; set status / duplicate; history clear / remove. Surface failures
  via `app.userMessage`.
- **"Session" wording.** SettingsView 89 ("Save Session as Workspace… in the session menu"), SettingsView 115 ("Open sessions"),
  MacRootView 94 ("saved with your session"), AppModel default name "New Session". Should be Workspace.

## D. Findings from the 2026-11-14 evening iPhone simulator pass

- **I25 — verse action capsule legibility (iPhone):** over red-letter text the regular Liquid Glass capsule lets the words behind it
  read through the icons (John 3:8 under the capsule). Tried a `.tint(systemBackground 0.45–0.6)` on `ReaderGlassCapsule` and UIKit
  `topEdgeEffect/bottomEdgeEffect = .soft` on the reader `UITextView`; neither changed the simulator rendering, so both were reverted.
  Check on a physical iPhone first (the simulator's glass blur differs); if still poor, register the floating capsule/dock with a
  `UIScrollEdgeElementContainerInteraction` so the text view's soft edge effect knows where the bars are, or use `.regularMaterial`.
- **I26 — FIXED (`.tint(.primary)` on iOS Go rows, verified in simulator)** — Go sheet rows were tinted blue (Open shortcuts and Recent rows render in the accent colour); iOS list rows that navigate
  normally use primary text with a tinted icon. `GoSheet.row` already sets `.foregroundStyle(.primary)` on the title but the Button
  tint wins on iOS — use `.buttonStyle(.plain)`-equivalent row styling (or `.tint(.primary)` on the label text).
- **I27 — FIXED (`LexiconService.searchFoldedTransliteration`, tested; Mac verified "shalom" → H7965 first):** lexicon diacritics — "chesed" finds H3777/H1136/H2618 but not H2617 *chêçêd* (mercy); "shalom" misses H7965. Needs a folded
  comparison pass in Swift (see HANDOFF next task 4).
- Verified OK on iPhone (iPhone 18 Pro, iOS 27 simulator): Psalm 3 title line (after the indent fix `30fc3d29`), Lexicon entry toolbar
  (‹ › Search in one glass capsule), Lexicon search (`05784f3f` capsule field), Strong's links in Derivation, verse tap → dashed outline
  + floating actions.
- **I28 — FIXED:** whole-chapter passage labels (Go Recent, palette, compare history) said "Psalms 3"; they now use the reader's chapter label ("Psalm 3").
- **I5 — DONE (iPhone, simulator-verified 2026-11-14):** scrolling the reader down fades/lifts the passage capsule and slides the dock away (36pt hysteresis, user scrolling only); scrolling up, the top or the end brings them back; resets on chapter change / leaving the reader.   `sqlite3 data/strongs_hebrew.db "select count(*) from (select bdb_def from entries where bdb_def<>'' group by bdb_def having count(*)>1)"`.
