# Mac reference cursor audit · 2026-11-23

Clicking a linked reference should open its existing destination. Hovering its text should show a pointing hand. Ordinary selectable or editable glyphs use the I-beam, empty space uses the arrow, and resize handles retain the resizing cursor.

## Verification

The offscreen AppKit probe uses the production cursor-rectangle implementation with wrapped linked text, ordinary prose, and a newline. Before the final geometry correction it recorded a pointing hand at x=188 on a line whose used text ended at x=170.74. The corrected rectangles pass for linked glyphs, neighboring prose, blank space after wrapped and final lines, blank space below text, resize handle exclusion, and nonselectable text. The same script checks the Mac Swift 6 target and aligned wrapped-text sizing.

From the repository root, rerun the saved local evidence with `zsh build/apple/qa-evidence/20261123/reference-cursor-probe/check.zsh`. The evidence directory is ignored by Git. The probe verifies rectangles registered with AppKit. Pointer transitions with the actual SwiftUI hierarchy still require a physical hover pass.
