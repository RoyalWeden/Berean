Status: **IMPLEMENTED + VERIFIED (scope below)** on Mac and iPhone. Was ❌/❌ (U17). Same `pdfs` / `pdf_highlights` / `pdf_bookmarks` rows and tab state (`{pdfId, title, page}` in the existing `pdf` tab type, Scripture space), no schema change, no new synced keys.

## Legacy audit
`src/platform/services/pdfService.ts` + `electron/ipc/pdf.ts` (copy to `userData/pdfs/<id>.pdf`, sha256 `file_hash`, attach a synced metadata row when the same file is imported, `fileMissing`), `PDFViewer.tsx` / `PdfPage.tsx` (highlights stored as rects normalised 0…1 to the displayed page, top-left origin; colours yellow/green/blue/pink/orange/purple @45%; bookmarks; find; copy-link `berean://pdf/<id>/<page>`).

## Native
- `BereanNotes/PdfService.swift`: exact SQL port (insert/findByHash/attachFile/list/get/setPageCount/rename/deleteRow-in-savepoint, highlights add/remove/setNote, bookmarks add/remove); `rects_json` written as `JSON.stringify` (x,y,w,h order, JS number format).
- `BereanNotes/PdfGeometry.swift`: normalised display rect ⇄ PDF page space for crop box origin and /Rotate 0/90/180/270.
- `apple/Shared/PdfViews.swift`: `PdfFiles` (`<UserLibrary>/pdfs`, QA-profile aware; import = hash → attach-if-missing else copy+insert; NSOpenPanel / UIDocumentPicker), `PdfLibraryView` (filter, rows with pages·size·date, "File not on this device" state, Open/Rename/Copy Link/Delete with confirm; deleting resets open tabs to the library), `PdfReaderView` (PDFKit continuous view, restores/saves `page` (debounced, no history entries), page count written once, floating selection bar with 6 colours + Copy + Search Scripture, tap-a-highlight bar with note/copy/remove, ⌘F find bar with all-match highlight and n of m, bookmark toggle, Contents inspector/sheet with Outline/Bookmarks/Highlights, Copy Link to Page, missing-file screen with hash re-attach). Highlights are drawn as unsaved PDFKit annotations — the PDF file is never modified.
- Entry points: Mac Go → PDFs, ⌘K palette "PDFs", Go sheet "PDFs", iPhone More → Study Tools → PDFs; `berean://pdf/<id>/<page>` deep links open the PDF at the page.
