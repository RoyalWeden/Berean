# Ask Berean — model-free path (G01 / G10) — 2026-11-20 (Claude Code)

Status: **IMPLEMENTED (core); iPhone VERIFIED (sim); Mac built.** No AI model is used or downloaded.

- `BereanBible/ModelFreeAsk.swift` (tested): the original's STOP words and keyword rules (≥3 letters, ≤6 distinct), KJV stem fallback (drop two letters from long words), word-study detection ("word study on X", "meaning of X", "define X", "strong's for X", "X in Hebrew/Greek", "Greek word for X") with language hint, and `best(_:for:)` — whole-word gloss match, most frequent first (fix found on sim: plain first hit gave G2143 euprepeia for "grace"; now G5485 cháris).
- `apple/Shared/AskBereanView.swift`: the original order — (1) Strong's id or word study → lexicon card (lemma, transliteration, gloss, definition, count) + first occurrences + Open Lexicon Entry; with no language named, the other language's best match is offered under **Also** and switches the card; (2) a reference → the verses; (3) keyword search over the KJV (all → any → stems), 12 verses, labelled "answered without an AI model on this device" (the original's NO_MODEL_INSTALLED/partial). Verse text honours the Word Replacer. Tapping a verse opens it.
- Entry points: iPhone More → Study Tools → Ask Berean and Go "ask"; Mac Go → Ask Berean… and the ⌘K palette.
- Verified on sim: "word study on grace" → H2580 card with Greek G5485 under Also → tap → G5485 card (284 occurrences, 1 Cor 1:3 "…Lord Yeshua Messiah"); "what does the Bible say about the Sabbath rest" → keywords "sabbath rest" → Lev 26:35, Luke 23:56, Lev 25:4 …; Return submits (multi-line field changed to single-line after it inserted newlines).
- Added later the same day (tested against the original's exclusion test cases): **Strong's comparison** ("compare H2617 and H7356" → entries side by side with counts), **translation parallel** ("How does Isaiah 7:14 read in the Septuagint?" → KJV and Brenton LXX), **exclusions** ("…but not human rulers", "…, not from Exodus" → removed from the query, applied as a filter; plurals tolerated). Verified on sim for all three (the Sabbath search returned Jer 17:22, Lev 23:15, Lev 25:4, Mark 2:27, Matt 12:5 — no Exodus).
- Not ported yet: multi-passage comparison (2–4 refs), follow-ups ("now only Greek", "the second"), collections scope, model-backed modes (G02–G08: owner decisions on models/keys).
