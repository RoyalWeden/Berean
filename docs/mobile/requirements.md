# Berean iPhone — Requirement Ledger

Source of truth for scope. Every requirement from the migration brief has a stable ID here.
**Requirements are never deleted.** A requirement is COMPLETE only when its implementation
exists, behaves correctly, works on iPhone (offline / via iCloud where required), desktop still
works, and tests cover the important behaviour.

Statuses: `NOT STARTED` · `INVESTIGATING` · `IMPLEMENTING` · `TESTING` · `COMPLETE` · `BLOCKED`

Columns: **Current repo implementation** is what exists on desktop today (from
`audit/*.md`); **Target** is the iPhone/shared behaviour; **Implementation / files** and
**Tests** are filled in as work lands; see `implementation-progress.md` for the per-phase
narrative.
